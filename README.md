## Auf GitHub Pages bereitstellen

1. ZIP entpacken. Die Dateien **aus dem Projektordner** samt `.nojekyll` ins Hauptverzeichnis des gewünschten GitHub-Repositorys übernehmen.
2. Für die Veröffentlichung der beiden mitgelieferten SRF-Ausschnitte die Freigabe für den vorgesehenen Zugriff klären. Alternativ die beiden MP4-Dateien beim Upload weglassen und die verlinkten SRF-Originale mit den angegebenen Zeitmarken abspielen.
3. Unter **Settings → Pages → Deploy from a branch** den Veröffentlichungsbranch und **/ (root)** auswählen. Die in GitHub angezeigte Pages-Adresse mit der Klasse teilen.

Lokal lässt sich die Seite mit `python3 -m http.server 8000` aus diesem Ordner unter `http://localhost:8000` öffnen. Die Seite braucht keinen Build und keine Konten. Antworten werden im Browserprofil gespeichert und als UTF-8-Markdown heruntergeladen. Auf gemeinsam genutzten Geräten nach dem Export die Antworten über die Seite löschen. Der ARD-Player wird erst auf Klick geladen. Die beiden SRF-Ausschnitte sind auf den lokalen Originalzeitmarken geschnitten.
